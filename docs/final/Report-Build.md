# Reproduce the technical report

The Markdown report is the source of truth. The PDF is generated from that source, actual Mermaid diagrams, and real screenshots. No live measurements are generated by the publishing tools.

Validated authoring dependencies: Python 3.13, ReportLab 5.1.0, markdown-it-py 4.2.0, pypdf 7.0.0, Mermaid 12.3.0, and the repository's Playwright Chromium. These are report-authoring dependencies, separate from the pinned application runtime.

```sh
python3 -m venv work/report-venv
work/report-venv/bin/pip install reportlab==5.1.0 markdown-it-py==4.2.0 pypdf==7.0.0
npm --prefix frontend ci
npx --prefix frontend playwright install chromium
npm install --prefix work/report-tools mermaid@12.3.0
MERMAID_DIST="$PWD/work/report-tools/node_modules/mermaid/dist" node docs/final/render_diagrams.mjs
work/report-venv/bin/python docs/final/build_pdf.py --help
work/report-venv/bin/python docs/final/build_pdf.py
```

Pass `--runtime-sha` with the exact tested runtime revision when generating a final delivery from a later documentation commit. The builder checks each diagram's source SHA-256 against the Markdown fence. Flowcharts are rendered top to bottom for print readability; labels and edges remain unchanged. Six diagrams are retained as PNG and SVG with a manifest.

Use Poppler `pdfinfo` and `pdftoppm -png` to render and inspect the actual PDF. Check the cover, contents, tables, diagram labels, code blocks and screenshot captions before delivery. Keep the final PDF, source Markdown, build scripts, diagrams, source revision, CI run reference and delivery checksums together. A successful PDF build is not a deployment or application test.
