A research-oriented platform exploring a practical distributed-systems question: can a deletion workflow report success while a supported copy remains? The project couples durable event processing and store-local fences with independent read adapters, then makes claims, contradictions, uncertainty and reproducible experiments understandable through an authenticated interface.

## Brief demonstration script

1. Show the declared data topology and actual readiness.
2. Create a synthetic fixture and observe real propagation.
3. Request deletion; pause at the operational completion claim.
4. Run independent verification and inspect its scope and target outcomes.
5. Open a recorded actual false-success finding and explain the contradictory evidence.
6. Export a sanitized report and explain one limitation: backups and future unknown copies are outside scope.
